偵探編號 02

誰是 PHP？誰是 SQL？

偵辦警語

以下內容大部分為 AI 整理；在本人複習驗證之前，正確性不予保證。請以偵探之眼謹慎偵查、交叉比對，勿將本筆記直接當成定案證據。

在 02-api_register.php 這類註冊 API 裡，同一行畫面常同時出現 $pdo、->exec() 與夾在括號裡的 $sql。乍看全寫在一起，其實是兩種身分：PHP 負責動手，SQL 是被打包送出的指令。

身分鑑定：執行者與指令內容

  1. 1. 誰是 PHP？（執行者）

    範圍：$pdo、->、exec( ... ) 還有結尾的分號 ;。

    怎麼認：

    • 只要看到字首有錢字號 $（變數），它就是 PHP。
    • 只要看見用來呼叫動作的箭頭 ->，它就是 PHP。
    • 這裡的 exec() 是 PHP 內建的函式（動作）。

    職責：它是坐在電腦裡的「執行官」，負責發動命令。

  2. 2. 誰是 SQL？（被執行的指令內容）

    範圍：夾在括號肚子裡的 $sql。

    怎麼認：

    • 雖然 $sql 貼著 PHP 的變數標籤（$），但它箱子裡面裝的核心內容，是你上一段寫的 "insert into members..." 那串英文。
    • 只要內容是 insert into、select、delete 這種跟資料庫溝通的語法，它在本質上就是 SQL 指令。

    職責：它是被打包好的「信件內容」，自己不會動，必須躺在 PHP 的 exec() 肚子裡，被 PHP 發射去資料庫。

一秒區分結論
PHP 是動詞與工具（例如：$pdo->exec() ➜ PHP 負責動手執行）。
SQL 是名詞與原料（例如：$sql ➜ 被執行的 SQL 指令字條）。
