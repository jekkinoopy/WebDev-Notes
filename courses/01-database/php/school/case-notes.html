標點符號卷宗

在 PHP 和 SQL 的世界裡，標點符號就像是我們在做包裝設計時的「出血線、裁切線和刀模規則」，少了一條或畫錯一個，主機在印刷（執行）時就會完全看不懂。

我們直接把這些符號分成「PHP 專用」與「SQL 資料庫專用」兩大陣營，看懂它們各自的「唯一專門用途」：

第一陣營：PHP 世界的標點符號

這是你寫在 PHP 檔案裡，用來控制程式、變數與拆包裹用的符號。

  1. $（錢字號 Dollar Sign）

    專門用途：「宣告變數（建立圖層名稱）」。

    白話解釋：在 PHP 裡面，只要看到這個符號，就代表後面那個字是一個「用來裝資料的特製箱子」。不管是 $pdo（連線箱）、$sql（字條箱），還是系統自帶的 $_POST（表單大包裹），開頭一定必加 $。

  2. ()（小括號）

    專門用途：「執行動作（函式）的發動開關，以及 SQL 的對齊桶」。

    白話解釋：只要看到英文單字後面緊貼著一對小括號 ()，這個單字百分之百是一個「動作」（例如 print_r()、exec()）。小括號就是啟動按鈕，並且負責把執行需要的原料塞在括號裡面。另外，當它寫在 SQL 的 VALUES 後面時，則是專門用來把資料群組起來、像拉鍊一樣一對一對齊欄位用的。

  3. []（中括號）

    專門用途：「拆包裹，指定拿哪一張貼紙的值」。

    白話解釋：當你手上拿著一個大包裹箱子（陣列）時，你不能直接把整箱倒出來，你必須用中括號指定裡面的名字。例如 $_POST['account']，這對中括號就是專門用來綁架 'account' 這個標籤的。

  4. {}（大括號）

    專門用途：「在雙引號的大字串裡，把變數精準框起來」。

    白話解釋：像在寫 SQL 那串長長的雙引號 "" 字串時，裡面密密麻麻都是字。如果你直接寫 $sql = "VALUES ($_POST['account'])"，電腦會分不清楚哪裡是字、哪裡是變數。

    這時候用 {} 把 {$_POST['account']} 緊緊包住，就是專門跟電腦劃清界線：「報告！大括號中間包著的這隻是一隻完整的 PHP 麥克風，請先把它裡面的字傳過來，不要跟外面的字搞混！」

  5. ;（分號）

    專門用途：「程式碼的句點」。

    白話解釋：這是你設定的嚴格規範！PHP 的每一行指令結束，右手小拇指一律要按下這個分號 ;。這是在跟主機講：「這一個動作我做完了，你可以看下一行了。」少寫一個，整頁直接當機。

第二陣營：SQL 世界的標點符號

這是寫在 SQL 字串裡面，專門用來跟 MySQL 資料庫溝通、對齊欄位與表格用的符號。

  1. `（反單引號／鍵盤最左上角 ~ 鍵）

    專門用途：「框住『資料表名字』與『欄位名字』」。

    白話解釋：這也是你的嚴格規則！只要在 SQL 指令裡面提到資料庫裡的表格名稱（例如 `members`）或是欄位名稱（例如 `account`、`password`），一律要用這對反單引號包起來。

    為什麼要這樣？這是為了跟電腦防呆。萬一你取的名字剛好跟 SQL 的內建指令（例如 name 或 date）撞名，加了反單引號，資料庫就會知道：「喔！這純粹是努比自己寫的欄位名稱，不是我的指令。」

  2. '（標準單引號）

    專門用途：「框住純文字的『值』」。

    白話解釋：當你要塞進資料庫的資料是「純文字、字串、日期」時，在 SQL 語法裡必須用單引號包起來。

    例如：'{$_POST['account']}'。外層這一對單引號，是專門寫給資料庫看的，告訴資料庫說：「待會這隻麥克風吐出來的資料，是一串純文字（例如 'noopy'），請用文字的形式把它存進格子裡。」
