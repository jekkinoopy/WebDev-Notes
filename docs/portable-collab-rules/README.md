# 可攜協作規範（搬離 WebDev-Notes 時複製）

把**整個資料夾內容**複製到新專案根目錄（與 `index.html` 同層）：

| 複製來源 | 新專案位置 |
|----------|------------|
| `.cursor/rules/*.mdc` | `.cursor/rules/` |
| `CURSOR-HANDOFF.project.md` | 更名為 `CURSOR-HANDOFF.md`，改專案名與路徑 |

複製後依專案修改 `repo-workflow.mdc` 裡的「辦案筆記路徑」等一兩行即可。

母 repo 完整規範仍以 [`.cursor/rules/repo-workflow.mdc`](../../.cursor/rules/repo-workflow.mdc) 與根目錄 `CURSOR-HANDOFF.md` 為準；本包擷取**獨立專案仍適用**的條目。
